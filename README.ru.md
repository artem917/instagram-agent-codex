# Instagram Agent для Codex

13 навыков создания контента в одном локально устанавливаемом плагине Codex. На основе ваших фактов, черновиков и предоставленных метрик он помогает готовить сценарии Reels, подписи, карусели, Stories, планы и ответы. В комплекте есть локальные Python-инструменты и редактор английского и русского текста с единым режимом `ru-social` для соцсетей.

Независимая MIT-адаптация [Instagram Agent Skill](https://github.com/Jakeschincariol/instagram-agent-skill) автора **Jake Schincariol**. Codex-порт поддерживает [artem917](https://github.com/artem917). Это инструменты подготовки черновиков: вы проверяете и публикуете материалы самостоятельно.

**Текущий релиз: [plugin-v0.1.0](https://github.com/artem917/instagram-agent-codex/releases/tag/plugin-v0.1.0) (предварительный релиз GitHub).** [Скачать ZIP плагина](https://github.com/artem917/instagram-agent-codex/releases/download/plugin-v0.1.0/instagram-agent-codex-0.1.0.zip). Плагин не отправлялся на модерацию и не опубликован в публичном каталоге OpenAI. Подключение Instagram-аккаунта, OAuth, API-интеграция и автопостинг в него не входят.

## Установка всего плагина

Требования:

- Клиент Codex с поддержкой плагинов и настроенным входом/моделью для интерактивной работы.
- Python 3 для встроенных инструментов; они используют только стандартную библиотеку. Проверено на Windows с Python 3.14.3.
- Git и доступ к сети для установки marketplace из GitHub. Учётные данные Instagram не нужны.

Команды ниже проверены в **Codex CLI 0.162.0-alpha.17.2**. В других версиях интерфейс установки может отличаться. Актуальный формат marketplace описан в [официальном руководстве OpenAI по упаковке плагинов](https://developers.openai.com/plugins/build/plugins).

Выполните в терминале, чтобы установить все 13 навыков из зафиксированного тега V0.1.0:

```text
codex plugin marketplace add artem917/instagram-agent-codex --ref plugin-v0.1.0
codex plugin add instagram-agent-codex@instagram-codex-local --json
codex plugin list --marketplace instagram-codex-local --json
```

Список должен показать установленный и включённый плагин версии `0.1.0`. Команды используют текущий профиль Codex. После установки начните новую сессию Codex. Копировать папки навыков по отдельности не требуется.

### Отдельный профиль Codex

Чтобы отделить настройки установки, задайте `CODEX_HOME` для текущего терминала **до** выполнения трёх команд выше. Выберите новую папку за пределами исходников плагина.

PowerShell:

```powershell
New-Item -ItemType Directory -Force -Path 'C:\codex-profiles\instagram-test' | Out-Null
$env:CODEX_HOME = 'C:\codex-profiles\instagram-test'
```

Терминал macOS/Linux:

```sh
mkdir -p "$HOME/codex-profiles/instagram-test"
export CODEX_HOME="$HOME/codex-profiles/instagram-test"
```

Запустите `codex` из того же терминала и войдите обычным способом, если отдельному профилю нужна авторизация. При последующих запусках этой установки используйте тот же `CODEX_HOME`. Примеры задают переменную окружения процесса, а не постоянную системную настройку. Нативная установка проверена на Windows; установка на macOS/Linux пока не проверена.

Другой вариант: из клона репозитория помощник создаёт чистый пакет и выполняет нативную установку в явно отдельный профиль:

```text
python scripts/install_plugin.py --codex-home /path/to/isolated-profile --dry-run
python scripts/install_plugin.py --codex-home /path/to/isolated-profile
```

Замените путь на свою папку. Помощник отказывается использовать стандартный глобальный профиль Codex и пересекающиеся папки исходников/кэша. Авторизация не копируется. При последующем запуске Codex задайте тот же `CODEX_HOME`. Подробнее: [руководство по установке плагина](PLUGIN.md).

Для установки из ZIP-релиза распакуйте архив и передайте полный путь его папки `instagram-agent-codex` команде `codex plugin marketplace add`, затем выполните те же команды `plugin add` и `plugin list`. Распакованные исходники должны находиться за пределами папки профиля/кэша.

## Первый запуск и примеры

Отправляйте эти примеры как **сообщения в Codex**, а не команды терминала. Установленные навыки плагина имеют префикс `instagram-agent-codex:`.

```text
$instagram-agent-codex:ig-plan Помоги начать работу. Язык ru-social. Уточни тему и примеры моего стиля, затем подготовь одну подпись на основе моих фактов.

$instagram-agent-codex:ig-caption Подготовь подпись к этому фото по указанным фактам. Дай два варианта начала и объясни предпросмотр. Используй ru-social.

$instagram-agent-codex:ig-reel Преврати эти заметки в Reel на 20 секунд. Предложи три хука, запусти оценку хуков и проверь хронометраж готового сценария.

$instagram-agent-codex:ig-human Отредактируй текст ниже в режиме ru-social. Сохрани факты, имена, числа, отрицания, ссылки и emoji. Не добавляй CTA, вопрос или хештеги.
```

Приложите к запросу настоящий текст, заметки или метрики. Первичная настройка выполняется через `ig-plan`; четырнадцатого навыка нет. Она помогает выбрать язык и локальную папку данных, по запросу сохраняет профиль авторского голоса и выполняет небольшую первую задачу. Аккаунт не подключается, публикации не планируются в сервисе.

## Английский и русский редактор

`ig-human` поддерживает три режима с единым русским движком:

| Режим | Поведение |
| --- | --- |
| `en` | Английский по умолчанию; регрессионные тесты относительно зафиксированного upstream. |
| `ru` | Естественный грамотный русский; литературная типографика разрешена. |
| `ru-social` | Разговорный русский для Instagram, VK, Telegram, Threads и других соцсетей. Обычные двойные кавычки, без длинного тире и пустых строк-разделителей, естественные абзацы и разнообразный ритм. |

Русские сценарии избегают шаблонных вступлений, пустых выводов, канцелярита и искусственной вежливости. Они не требуют вопроса, CTA или хештегов в конце, не выдумывают личный опыт и не имитируют орфографические ошибки. Лимиты длины и хештегов площадок задаются необязательными настройками, а не отдельными языковыми движками.

Нормализация символов, обнаружение стилистических проблем и смысловые рекомендации разделены. Автоматические изменения формулировок намеренно ограничены. Неоднозначная пунктуация или конфликт с защищёнными данными возвращает `NEEDS_REWRITE`, чтобы не менять смысл молча. Инструменты проверяют распознанные имена, идентификаторы, числа, URL, отрицания и emoji-последовательности, включая ZWJ; полное сохранение смысла и авторского голоса требует проверки в контексте. Дополнительные точные фрагменты можно защитить через `--preserve`.

Подробнее: [русский сценарий работы](skills/ig-human/references/ru.md) и [отчёт русских тестов](RU_TEST_REPORT.md), включая ложные срабатывания и непроверенные свойства. Это редакторские эвристики, а не определение ИИ-авторства или сервис удаления водяных знаков.

## Локальные Python-команды

В **клоне репозитория** используйте команды ниже со своими входными файлами UTF-8. В установленном плагине Codex находит скрипты по пути загруженного навыка в кэше; нельзя считать, что там есть клон или `.agents/skills`.

```text
python skills/ig-human/humanize.py draft.txt --mode ru-social --report
python skills/ig-human/detect.py draft.txt --mode ru-social --json
python skills/ig-reel/hookscore.py hooks.txt --json
python skills/ig-reel/beats.py script.txt --target 20 --json
python skills/ig-caption/caption.py caption.txt --json
python skills/ig-viral/swipe.py reels.tsv --out swipe.md --json
```

Шесть инструментов принимают файлы или stdin (`-`); параметры описаны в `--help`. UTF-8 BOM, CRLF и пути с пробелами/кириллицей покрыты тестами. Пути с пробелами заключайте в кавычки. `swipe.py` принимает TSV; поля описаны в [сценарии исследования](skills/ig-viral/SKILL.md).

Русская нормализация завершает работу с кодом `0` для `CLEAN`, `1` для `REVIEW` и `3` для `NEEDS_REWRITE`; неверные CLI-аргументы дают `2`. При `NEEDS_REWRITE` JSON содержит `text: null` и кандидат для проверки; файл готового текста не записывается. С `--json` нормализация выводит JSON в stdout вместо записи `--out`. Читайте вердикт каждого инструмента: успешный запуск не подтверждает качество текста. Исходные английские оценки хуков/подписей и пороги не являются метриками качества русского языка.

## Локальные данные и прежние установки

Необязательные профили авторского голоса, swipe-файлы и планы используют папки в порядке: `INSTAGRAM_AGENT_HOME`, затем `CODEX_HOME/instagram`, затем `~/.codex/instagram`. При первичной настройке можно выбрать папку внутри рабочего проекта. Для собственных фактов и примеров стиля есть [шаблон voice.md](templates/voice.md). Личные данные храните вне кэша плагина. Локальные Python-инструменты не отправляют черновики в сервис; запросы Codex обрабатываются вашей настроенной моделью/сервисом.

Прежний установщик навыков в отдельный проект поддерживается. Из клона репозитория:

```text
python scripts/install.py --project /path/to/existing-project --dry-run
python scripts/install.py --project /path/to/existing-project
```

Он устанавливает все 13 папок в `.agents/skills` выбранного проекта, использует вызовы без префикса, например `$ig-reel`, и не меняет глобальные настройки. При отличающихся существующих файлах установщик отказывается их перезаписывать. Выберите плагин или standalone-установку, чтобы не создавать дубли навыков; сценарии работы сохранены в обоих вариантах.

## Что изменилось относительно Claude-оригинала?

Сохранены творческие методики и имена 13 навыков. Порт добавляет нативную упаковку плагина Codex, вызовы с пространством имён, onboarding, прежний проектный установщик, исправления CLI для Windows/UTF-8, явные вердикты проверки и общий русский редактор со словарём и тестами сохранности. Используется portable Agent Plugins 1.0 и совместимый манифест Codex; V0 не регистрирует ни одного MCP-сервера.

## Реальные ограничения

- Нет Instagram API, OAuth, подключённых аккаунтов, живых Insights, автопостинга, отправки сообщений и планировщика. [Исследование будущего Instagram MCP](docs/INSTAGRAM_MCP_PLAN.md) является проектом, а не работающей интеграцией.
- Нет публикации, отправки на модерацию или одобрения в каталоге OpenAI. Установка выполняется через этот репозиторий/локальный marketplace.
- Оценки эвристические; короткие тексты, юмор и нестандартные структуры могут требовать проверки. Не обещается вирусность, определение ИИ-авторства, удаление водяных знаков или универсальное исправление грамматики/сохранение смысла.
- Экспорт каруселей в PNG/JPEG требует настоящего рендерера и визуальной проверки. Монтаж, транскрибация и браузер являются необязательными внешними возможностями, а не встроенными сервисами.
- Нативная установка на других ОС/клиентах, интерфейс настройки desktop и будущие лимиты площадок не проверены. Доступ к Codex и использование модели зависят от вашей конфигурации аккаунта.
